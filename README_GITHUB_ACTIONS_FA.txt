ساخت APK با GitHub Actions

1) این پروژه را در GitHub به صورت یک Repository جدید قرار دهید.
2) نام Repository می‌تواند SLTP_Calculator باشد.
3) بعد از Upload کردن فایل‌های پروژه، به بخش Actions بروید.
4) Workflow با نام Build Android APK را انتخاب کنید.
5) اگر Workflow خودکار اجرا نشده بود، روی Run workflow بزنید.
6) بعد از تمام شدن Build، وارد اجرای موفق Workflow شوید.
7) در قسمت Artifacts، فایل SLTP-Calculator-APK را دانلود کنید.
8) فایل دانلودشده ZIP است؛ آن را باز کنید تا app-debug.apk را ببینید.
9) فایل app-debug.apk همان فایل نصب برنامه روی گوشی است.

نکته: این روش به Android Studio روی کامپیوتر شما نیاز ندارد. Build روی سرورهای GitHub Actions انجام می‌شود.
